# System Design Learning Journal

This directory is the durable curriculum state for the progressive system-design program.

- `curriculum.md`: dependency-driven curriculum and roadmap.
- `progress.md`: current progression state and completed concepts.
- `lessons/`: one lesson record per completed day.

The repository is the source of truth. Future sessions must inspect these files and relevant lessons before selecting the next concept.
